# Telegram: прогнозы по темам

Первая версия: чтение разрешённых открытых источников через Telethon, публикация ботом в темы закрытой супергруппы, ручной доступ на 30 дней. Тариф 299 ₽ отображается информационно. Приёма платежей нет.

## Подготовка

Python 3.12+, `python3 -m venv .venv`, затем `.venv/bin/pip install -r requirements.lock`.
Скопируйте `.env.example` в `.env`, заполните локально, не коммитьте секреты.
Получите `TG_API_ID` и `TG_API_HASH` в my.telegram.org, токен бота — у BotFather.
Создайте закрытую супергруппу, включите темы, создайте темы для источников.
Боту нужны права приглашать/одобрять участников, блокировать участников и публиковать сообщения. Отключите другие публичные способы входа в группу.
`ADMIN_IDS` — числовые ID администраторов через запятую. `GROUP_ID` — числовой ID группы вида -100… .

Из каталога репозитория:

```bash
set -a
source .env
set +a
.venv/bin/python -m betbot.login
.venv/bin/python -m betbot.main
```

Вход аккаунта выполняется один раз интерактивно: телефон, код Telegram и при необходимости пароль 2FA вводятся локально в терминале. Не отправляйте их в чат. `data/reader.session` даёт доступ к аккаунту: защищайте и резервируйте его как секрет. Для рабочего аккаунта рекомендуется отдельный номер.

## Управление

Напишите боту `/start`. Администратор управляет ботом в личном чате:

- `/admin` — справка.
- `/source -1001234567890 42` — связать ID разрешённого канала с ID темы группы.
- `/sources`, `/remove CHANNEL_ID` — список и отключение источников.
- `/grant USER_ID` — выдать/продлить доступ на 30 дней.
- `/revoke USER_ID` — удалить подписку и заблокировать участника.
- `/subscribers` — список активных подписок, срок в Unix seconds.

После выдачи доступа пользователь нажимает `/start`: получает ссылку с заявкой на вступление на 15 минут. Бот одобряет только действующих подписчиков. Истёкшие подписки проверяются раз в минуту. Администраторы Telegram не должны быть платными подписчиками: бот не сможет удалить администратора группы.

Используйте существующий checkout в изолированной облачной задаче; отдельный Git worktree не требуется. При перезапуске заново загрузите `.env` и запустите `python -m betbot.main`; база и сессия сохраняются в `data/`.

## Ограничения прототипа

Публикуются только новые сообщения, доступные аккаунту во время работы. История и пропущенные при остановке сообщения не загружаются. Источник открытого канала должен быть доступен аккаунту; для получения обновлений подпишитесь на канал этим аккаунтом. Названия авторов в метаданных пересылки не передаются; подписи, ссылки и водяные знаки внутри контента не удаляются. Форматирование не сохраняется, альбомы отправляются отдельными вложениями. Опросы и другие специальные типы медиа не поддержаны. При частичной сетевой ошибке возможны пропуски/повторы: перед коммерческим запуском необходимы очередь доставки и журнал повторных попыток. Большие вложения могут превышать лимиты Bot API.

Нет веб-админки, автоматических платежей и обработки редактирований/удалений. Поддерживается один процесс и одна группа. SQLite достаточно для начальной версии; резервируйте `data/bot.sqlite3`.

## Проверки

`python3 -m unittest discover -s tests -v` — расчёт срока подписки, продление и повтор платежного события/операции выдачи. Полная проверка требует настоящих токенов, авторизованного аккаунта и группы: подключить тестовый источник, опубликовать текст/вложение, проверить нужную тему, выдать доступ тестовому пользователю и проверить вступление и отзыв.
